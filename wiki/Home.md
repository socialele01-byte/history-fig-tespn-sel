## 檔案結構

八份檔案放在同一個資料夾，全部相對路徑連結，可離線開啟。

| 檔案 | 角色 | 互動 |
|---|---|---|
| `index.html` | 入口網站（左側欄 + iframe） | 導覽連結 |
| `00_教學包總覽_先讀我.html` | 交接索引 | 8 個檔案連結 |
| `FIG-TESPN社會科思考鷹架.html` | 課堂學習單 | 案例切換、填寫、列印 |
| `FIG-TESPN社會科_V2_莫那魯道骰子抉擇.html` | 五關卡互動遊戲 | 選路、擲骰、揭曉 |
| `FIG-TESPN社會科_V2_教師引導提問單.html` | 教師備課參考 | 無（純閱讀） |
| `FIG-TESPN社會科_工作坊講稿_8頁精簡版.html` | 上台講稿 | 無（純閱讀） |
| `FIG-TESPN社會科_工作坊流程小抄.html` | 控時報時表 | 無（純閱讀） |
| `*.pptx` × 3 | 工作坊簡報 | 不在網站內 |

**七個 HTML 檔各自獨立、樣式內嵌**，沒有共用的外部 CSS。這是刻意的：檔案可以單獨寄出、單獨開啟、離線使用。代價是設計 token 必須在七個檔之間手動同步。

## 三條不可違反的規則

1. **不在 `:root` 之外寫死任何色值。** 一律 `var(--token)`。
2. **填色承載文字時，用 `.sw-*` 配色對，不要自己配。** 亮暖色（`--amber`／`--gold`）必須配深墨字，其餘配白字。
3. **七個檔的 `:root` 區塊必須完全一致。** 改一個就要同步七個。
